# Mehrab for macOS — Homebrew tap

```sh
brew install --cask dev-ahmedhany/mehrab/mehrab
```

Update with `brew upgrade --cask mehrab`. Remove with `brew uninstall --cask mehrab`
(add `--zap` to also delete the app's settings and cached data).

The app is signed with a Developer ID and notarized by Apple. Releases on this
repo hold the downloads; `Casks/mehrab.rb` is updated by the release script in
the app repository.
